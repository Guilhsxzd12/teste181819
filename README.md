# KINDLE BOOK

Biblioteca digital privada, moderna e responsiva, com leitura online e administração completa.

## Recursos

- Login e cadastro com Supabase Auth
- Painel administrativo para livros, categorias e usuários
- Upload de PDF/EPUB e capas
- Armazenamento e organização no Google Drive
- Leitor online, favoritos e progresso de leitura
- Integração com Kindle
- Integração com Telegram para vinculação, avisos e envio de livros
- Planos e assinaturas preparados no banco de dados
- Implantação otimizada para Vercel

## Tecnologias

Next.js 16, React 19, TypeScript, Supabase e Google Drive API.

## Configuração

1. Copie `.env.example` para `.env.local`.
2. Configure as credenciais do Supabase, Google Drive e Telegram.
3. Execute as migrações da pasta `supabase/migrations`.
4. Instale as dependências com `npm install`.
5. Inicie com `npm run dev`.

> Este repositório é um projeto separado. O site Biblioteca Virtual original não é alterado.
